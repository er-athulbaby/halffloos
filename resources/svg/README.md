# Icons

Phosphor Icons (https://phosphoricons.com), MIT licensed, copied from
`@phosphor-icons/core` v2.1.1 at the `regular` weight.

They are committed here rather than pulled from node_modules at runtime so the
deployed app carries no icon dependency. To add one, copy the file from
`node_modules/@phosphor-icons/core/assets/regular/` and reference it by name
through `<x-icon name="..." />`.
